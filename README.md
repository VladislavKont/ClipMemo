# ClipMemo — Менеджер буфера обмена

**Версия:** 2.0.2611.14 · **Лицензия:** бесплатно для всех · **Платформа:** Windows 10/11 (x64)

ClipMemo — небольшая десктопная утилита, которая молча следит за буфером обмена и сохраняет всё, что вы копируете: текст, ссылки, код, номера телефонов, e-mail, банковские карты и скриншоты. Всё это доступно в удобной истории с мгновенным поиском — один клик, и любая старая запись снова в буфере.

---

## Возможности

### История буфера обмена
- Автоматическое сохранение **всего** скопированного: текста и изображений (скриншоты, картинки).
- Один клик по карточке — запись снова в буфере обмена.
- Дубликаты не сохраняются: если запись уже есть в истории, она не задваивается.
- Удалённая запись не появляется заново, пока её содержимое лежит в буфере обмена.

### Умное распознавание типов
Каждая запись автоматически классифицируется и получает свою иконку для мгновенного визуального поиска:

| Тип | Иконка | Примеры |
|---|---|---|
| Ссылка | 🔗 | https://..., www.... |
| E-mail | 📧 | any@mail.com |
| Телефон | 📞 | +7 (999) 123-45-67, любые международные форматы |
| Банковская карта | 💳 | 16–19 значные номера карт |
| Код | 💻 | фрагменты исходного кода |
| Изображение | 🖼️ | скриншоты, картинки из буфера |
| Текст | 📝 | всё остальное |

Фильтрация телефонов и карт разделена — ложных срабатываний между ними нет.

### Поиск и избранное
- Мгновенный поиск по подписям записей при вводе.
- ✏️ **Подписи к записям**: на каждой карточке — поле подписи между заголовком и датой. По умолчанию подпись равна заголовку записи. Значок ✏️ в правом конце поля активирует правку: **Enter — сохранить, Esc — отмена**. Если подпись стереть полностью, на карточке снова покажется заголовок.
- ⭐ **Избранное** — закреплённые записи живут на отдельной вкладке и **никогда не удаляются автоматически** (даже если срок хранения истёк).
- Звёздочка на карточке или в контекстном меню — добавить/убрать из избранного.

### Изображения
- Сохранение скопированных картинок и скриншотов прямо в базе.
- Наведение курсора на карточку — всплывающее превью полного размера.
- Клик — изображение снова в буфере обмена.

### Хранение и автоматическая очистка
- Настройка срока хранения: **3, 7, 14, 30 дней или «Всегда»** (не удалять никогда).
- Просроченные записи удаляются автоматически **при запуске программы** — удалённое не мелькает на экране.
- Избранное очистка не трогает.

### Производительность
- История подгружается **порциями по 100 записей**: первая сотня открывается мгновенно, дальше — кнопка «⬇ Загрузить ещё». Список не тормозит даже на огромной истории.
- Двойная буферизация и отключение перерисовки на время обновления — карточки не мерцают.

### Прочее
- Горячая клавиша **Alt+V** — показать/скрыть окно из любого приложения.
- Сворачивание в системный трей.
- Автозапуск вместе с Windows (включается в настройках).
- 6 цветовых тем: Catppuccin Dark, Dark Modern, Nord Dark, Light Clean, One Light, Solarized Light.
- Два языка интерфейса: русский и английский.
- Окно «О программе» с QR-кодом для доната.

## Установка

**Скачать:** страница [Releases](https://github.com/VladislavKont/ClipMemo/releases) — берите `ClipMemo_setup.exe` (бинарники в репозиторий не коммитятся).

### Установщик (рекомендуется)
1. Скачайте `ClipMemo_setup.exe`.
2. Запустите — установка в `C:\Program Files\ClipMemo`, ярлыки в меню «Пуск» и (по желанию) на рабочем столе.

### Portable
Скопируйте `ClipMemo.exe` в любую папку и запускайте оттуда. Все данные (история, настройки) хранятся в файле `clipmemo.db` рядом с программой.

### Требования
- Windows 10/11 (x64).
- .NET **не требуется** — runtime встроен в exe (поэтому файл большой, ~150 МБ).
- Права администратора не нужны для portable-версии.

> **Обновление поверх:** при установке новой версии поверх старой история и настройки **сохраняются** — база `clipmemo.db` установщик не трогает.

## Бэкап и восстановление

Вкладка **Настройки → 💾 Бэкап**:
- Создаёт копию базы в `Документы\clipmemo_backup.db`.
- **Внимание:** перед созданием бэкапа вся не-избранная история очищается и база уплотняется (VACUUM). Бэкап содержит только избранное.

Вкладка **Настройки → 📂 Из бэкапа**:
- Восстанавливает базу из `Документы\clipmemo_backup.db`, полностью заменяя текущую историю и настройки. Операция необратима — текущая база будет перезаписана.

## Доступ к базе для сторонних утилит

База `clipmemo.db` — обычный файл **SQLite 3**, лежит рядом с `ClipMemo.exe`. Сторонние утилиты могут читать и использовать записи напрямую, без встроенного API.

### Схема данных

```sql
CREATE TABLE history (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    content    TEXT UNIQUE,          -- текст записи; для изображений: "data:image/png;base64,..."
    created_at TEXT,                 -- дата и время: "дд.ММ.гггг ЧЧ:мм"
    is_fav     INTEGER DEFAULT 0,    -- 1 = в избранном
    type       TEXT DEFAULT 'text',  -- text | url | card | code | phone | email | image
    caption    TEXT                  -- подпись записи (по умолчанию = заголовок)
);

CREATE TABLE settings (
    key   TEXT PRIMARY KEY,
    value TEXT
);
```

### Рекомендации

- **Открывайте базу только на чтение**, пока ClipMemo запущен — он кратковременно блокирует файл при записи:
  ```
  Data Source=clipmemo.db;Version=3;Mode=ReadOnly;Default Timeout=5;
  ```
- Если нужна **запись** — сначала скопируйте файл (`clipmemo_copy.db`) и работайте с копией, иначе можно получить `database is locked` или повредить базу.
- **Изображения** хранятся в поле `content` в виде base64-строки `data:image/png;base64,<данные>` — декодировать их утилите нужно самостоятельно.
- Поиск как в программе: `SELECT ... FROM history WHERE IFNULL(caption, '') LIKE '%запрос%' ORDER BY id DESC;`
- Базу можно открывать любым SQLite-клиентом: `sqlite3.exe`, Python (`sqlite3`), PowerShell, DB Browser for SQLite и т.д.

## Нюансы и известные особенности

- **Избранное не удаляется никогда** — это by design, даже при сроке хранения «3 дня».
- Запись удаляется с первого раза и не «возрождается», пока её содержимое в буфере обмена — программа помнит, что вы её только что стёрли.
- «Всегда» в настройке срока хранения означает **«не удалять никогда»**.
- Автоматическая очистка старых записей происходит **при запуске программы** и при ручной смене срока хранения, а не раз в день по таймеру. Если программа висит в трее неделями — запускайте её заново, чтобы почистить.
- Если программа запущена из папки без прав на запись, база не сохранится — используйте установщик или папку вне `C:\Program Files`.
- История и настройки лежат в `clipmemo.db` рядом с exe. **Не удаляйте этот файл**, если не хотите потерять историю.
